One line for make.fun's "Last Text at One Percent" bounty: the last message someone sends as their phone dies at 1% battery. It tries to fit love, a farewell, and one last practical instruction into a single breath — the priorities are the joke.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `out/entry.txt` locally, or to `/output/entry.txt` where the competition runs it. The line is a single line under 200 characters.
